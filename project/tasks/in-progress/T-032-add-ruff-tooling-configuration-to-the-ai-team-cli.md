## Description

The `ai-team` CLI under `cli/` has no formatter or linter configured. Per approved
spec S-001 (`project/specs/github-actions-ci-for-cli-tests-and-ruff-formatting-checks.md`,
Phase 1), adopt Ruff by declaring it as a dev dependency and adding its configuration
to `cli/pyproject.toml`.

This task adds **only** the tooling configuration. It does not reformat existing code —
that is T-033.

- Add `ruff` to the `[dependency-groups] dev` array in `cli/pyproject.toml`.
- Add a `[tool.ruff]` section: `target-version = "py314"` (aligned with the existing
  `requires-python = ">=3.14"`) and `line-length = 88`.
- Add a `[tool.ruff.lint]` section: `select = ["E", "F", "I"]` (pycodestyle errors,
  pyflakes, import sorting). This resolves spec S-001's open `[TODO]` on rule selection
  with a standard minimal set.
- Run `uv sync` so `cli/uv.lock` records `ruff`.
- Do not change any other `pyproject.toml` settings.

## Acceptance Criteria

AC-1: The `cli/pyproject.toml` `[dependency-groups] dev` array shall include `ruff`.
AC-2: The `cli/pyproject.toml` file shall contain a `[tool.ruff]` section with `target-version = "py314"` and `line-length = 88`.
AC-3: The `cli/pyproject.toml` file shall contain a `[tool.ruff.lint]` section with `select = ["E", "F", "I"]`.
AC-4: WHEN `uv run ruff --version` is executed in `cli/` THE SYSTEM SHALL print a Ruff version and exit 0.
AC-5: The `cli/uv.lock` file shall record the `ruff` package.

## Dependencies

- None

## Files to Touch

- `cli/pyproject.toml` — add `ruff` to dev dependencies; add `[tool.ruff]` and `[tool.ruff.lint]` sections
- `cli/uv.lock` — regenerated by `uv sync` to include `ruff`


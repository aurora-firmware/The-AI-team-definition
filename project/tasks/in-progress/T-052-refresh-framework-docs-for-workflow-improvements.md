## Description

Refresh framework-level documentation so the approved workflow changes are
visible outside the skill bodies. This task documents change-request as a
lighter intake path, clarifies that docs/tests are planned during spec
breakdown, records the Gate 2 technical-review boundary, and explains how root
guidance files support test-command discovery.

AC-1: The system shall document change-request as the lighter path for smaller
changes.
AC-2: The system shall document that spec breakdown plans documentation and test
updates as implementation work where relevant.
AC-3: The system shall document that Gate 2 review focuses on technical
task-plan readiness.
AC-4: The system shall document that project test commands belong in root
guidance or referenced project-local docs.

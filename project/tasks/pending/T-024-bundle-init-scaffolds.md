# Bundle init scaffold assets and add sync helper

## Description

Bundle the framework's installable assets so `ai-team init` (T-025) can scaffold them into a fresh repo.

Create `cli/src/ai_team/init/scaffolds/` containing three subtrees:
- `project/` — empty state-folder skeleton (`specs/`, `tasks/{pending,in-progress,completed,blocked}/`, `bugs/{open,in-progress,resolved}/`, `decisions/`, `docs/`) with a `.gitkeep` in each leaf folder.
- `claude/` — a snapshot of `.claude/agents/` and `.claude/skills/` from this repo, post-migration (rely on T-019..T-023 having completed so the snapshot already references the CLI).
- `ai-process/` — a snapshot of this repo's `ai-process/` directory.

To keep the bundled snapshots in sync with the source tree without a Hatch build hook, add a Python sync helper at `cli/scripts/sync_init_scaffolds.py` that copies the three subtrees from the repo root into `cli/src/ai_team/init/scaffolds/`. Document in the task that this script must be run before `uv build` to refresh the bundle.

## Acceptance Criteria

AC-1: WHEN `python cli/scripts/sync_init_scaffolds.py` runs from the repo root THE SYSTEM SHALL replace `cli/src/ai_team/init/scaffolds/{project,claude,ai-process}` with current copies from the repo.
AC-2: The system shall include `.gitkeep` markers in every empty leaf folder of the bundled `project/` skeleton.
AC-3: WHEN `uv build` runs after the sync script THE SYSTEM SHALL include all bundled scaffold files in the resulting wheel.
AC-4: The system shall not include the consuming project's `project/` artifacts (specs/tasks/bugs/decisions content) in the bundled scaffold — only the empty skeleton.

## Dependencies

- `T-019` — status-report skill migrated before snapshot
- `T-020` — new-task skill migrated before snapshot

## Files to Touch

- `cli/scripts/sync_init_scaffolds.py` — sync helper
- `cli/src/ai_team/init/__init__.py` — empty package marker
- `cli/src/ai_team/init/scaffolds/` — generated by the sync helper (committed for reproducible builds)

## Verification

```bash
cd cli && python scripts/sync_init_scaffolds.py && uv build && unzip -l dist/*.whl | grep init/scaffolds/
```
